# Neon Copter

A modern take on the classic 2000s Helicopter / Copter Flash game.

Hold to fly up, release to fall. Navigate through the cave and dodge obstacles for as long as you can.

## How to Play

- **Hold** (mouse / finger / Space / ↑) → Helicopter goes up  
- **Release** → Helicopter falls down  
- Avoid the walls and obstacles  
- Distance = Score  

## Features

- Smooth helicopter with rotor, tilt & thrust flame
- Cave terrain that changes as you go
- Obstacles:
  - Floating blocks
  - Spikes from the ceiling
  - Spikes from the floor
- Particle effects & smoke trail
- Sound effects
- Live high score (updates in real time)
- Mobile-friendly

## Controls

| Input              | Action     |
|--------------------|------------|
| Hold mouse / finger| Fly up     |
| Release            | Fall down  |
| Space / Arrow Up   | Fly up     |
